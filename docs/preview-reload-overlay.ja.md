# 紙芝居プレビューのリロード状態UI

公開済みKamishibai rc.34は、リロード状態ボタンをviewport基準で配置する。Editorは`src/components/stage/preview-reload.css`でこの既存オーバーレイの表示を統合する。

- 上辺の3アンカーは、Editorメニューとステージ操作バーの高さを空ける。ステージ全画面では操作バーの高さだけ空ける。右上はボタン1個分と余白を左へ寄せ、作品側の閉じる操作も空ける。
- Runtimeの希望アンカー、確定アンカー、保存値、リロード方針を変更しない。UIのクリック・キーボード処理はRuntimeが所有する。
- オーバーレイは既存のステージオーバーレイ層に置き、GUIのモーダルより下に保つ。
- 設定パネルはviewport内でスクロールできる。読み上げ用ライブ領域は視覚レイアウトに影響させない。
- 公開済みSB3の改変、拡張コードの書き換え、権限の迂回は行わない。

検証は公開rc.34の通常のproject_url読み込みと許可操作を使う。1280×600/800、上辺アンカー、設定開閉、位置の保存、リサイズ、ステージ全画面の出入りを対象にする。

ロールバックは今回のCSSとimportをrevertするか、配布サイトのGUI固定SHAを直前に戻してPagesを再公開する。
