# 標準の編集機能

ブロック編集ダイアログ、ソースフォーム、共通フォーム、固定入力、子孫編集、一括セキュリティ確認を標準で提供します。
通常の `editor.html?lang=ja` で利用できます。有効化だけを目的にしたURLスイッチと、その読取りmoduleは撤去しました。

拡張の実行方法はセキュリティダイアログで利用者が選択します。host独自の許可policy、既存artifactの能力交渉、起動時addon完了待ち、競合時の保存抑止は維持します。

対象の単体70件と変更srcのlint、実Chromiumによる固定入力・日英保存・破棄・検証・子孫編集・共通フォーム・SB3のファイル/URL再読込・一括許可を検証します。明暗テーマでは入力のエラー色とラベル位置も確認します。macOSのネイティブファイル選択画面はこの検証には含めません。

問題時はGUIの変更と公開ページのGUI pinを一組でrevertします。保存形式は移行しません。
既存の段階導入文書にあるURLフラグ・OFF/ON組合せは導入当時の記録です。現行の標準動作は本書に従います。
